# Contributing / 参与贡献

Please file a reproducible issue with the version and a small synthetic example. Do not upload private media, keys, or real transcripts. Discuss larger changes first. Run `python -m pytest tests -q` and Node syntax checks before a pull request. Keep Chinese/English UI text and guides in sync. Contributions to original project code use MIT; do not import third-party code without its license and attribution.

请使用合成数据复现，提交前跑测试，同步维护中英文，并为第三方代码保留许可。
