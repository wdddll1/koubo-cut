# Security / 安全

Do not open a public issue containing keys, private media or transcripts. For a vulnerability, use GitHub's private vulnerability reporting when available, or open a minimal issue asking for a private contact without exploit details. Do not expose the local HTTP service to the network. Only the current beta is maintained.

请勿公开密钥、私人素材和文稿。安全问题优先使用 GitHub 私密漏洞报告；未启用时先提交不含敏感细节的联系请求。不要把回环服务暴露到公网。
