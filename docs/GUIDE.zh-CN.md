# 中文使用教程

## 安装、数据与语言

完整解压发布 ZIP，运行根目录的口播快剪.exe。不要只复制 exe，也不要在 ZIP 内直接启动。首次下载需访问 Hugging Face、GitHub 和 PyPI；无法连接时先检查网络，下载失败后可重试。解压位置须可写。安装过剪映或 PR 才能在对应编辑器中打开输出。

页面右上角切换 English / 中文。界面语言同时决定识别模型，不自动检测混合语言。英文与中文素材列表独立；切换不会覆盖原项目。首次切换英文需下载英文模型。两个剪辑软件区块也拥有独立项目列表。AE 暂不支持工程生成。

文件夹：runtime 是程序，data 是所有本机工作数据，docs 是说明。data/cache 可在关闭软件后清理，但再次试听可能需要重建缓存；删除 data/projects 会丢失复核结果。原视频按路径引用，移动原视频可能需要重新导入。请在升级前备份 data 与原素材。

## 识别与人工复核

1. 选择剪映或 PR，填写本机视频路径，导入。
2. 下载语音与说话人模型。点击按当前配置一键识别，完成文稿和本地声纹分组。它不会自动调用 AI 整句修正。
3. A/B 只是声音分组，不是真实身份。试听有歧义的内容，选中字词手工修正人物；重叠或不确定标签必须特别核对。
4. 手工修改断句与文字。每段应是适合剪辑的短句，不能把所有对话合成一整段。AI 断句目标约 9 字/英文约 9 词，并非强制长度。
5. 若需要，再单独触发 AI 整句校正：保留人工人物与时间轴，纠正错字及断句，语气助词独立标出。试听后决定接受哪些建议。模型可能误改，不能免复核。

## AI、主题与信息浓缩

在设置中输入自己的 DeepSeek Key 和模型名；不要把 Key 放入项目或发给他人。服务关闭后需重新输入。兼容接口是否可用以供应商当前配置为准。

“提炼主体”返回建议标题、主题、精简主体与要点，可在页面编辑和复制，不会自动改剪辑。

信息提取度针对整段视频文稿，20% 最压缩，100% 不额外浓缩。该值是信息/文稿保留目标，不承诺视频时长严格达到同一比例。AI 会给出候选范围，需人工复核。可全选/取消建议。

## 工程生成

- 勾选“按照人工复核直接裁剪”：按当前人工断句时间戳切片，不要求再经 AI 审核。
- 审核模式：黑色底板贯穿主轨，保留对话、无内容/助词、建议删除内容分布在画中画轨道，方便编辑器内复核。
- 直接删除：勾选后去掉删除范围并合并保留内容，字幕按相同映射移动。建议先保存审核版。
- 输入清楚的草稿名称，选择是否添加字幕。剪映填写真实草稿目录后生成，再在剪映中打开新草稿。
- PR 下载并完整解压交换包，Premiere 中导入 XML 并打开序列。保留字幕 PNG 文件夹和原视频路径；缺失素材应在 PR 中重连。PNG 是透明图形字幕，SRT 可另行导入为原生字幕，但不会自动与视频绑定。

## 精剪后一次合拢空隙

先在编辑器保存。剪映选择草稿文件夹，PR 先导出 FCP XML 后选择该 XML，在工具“精剪合拢”中执行。它创建新副本，不覆盖原工程。视频与字幕共用一套移动映射，短字幕保留相对视频的时间差；不要单独把字幕全部对齐。检查新工程再继续编辑。遇到复杂转场/嵌套/变速拒绝提示时，简化副本后再试。

## 排查

模型失败：重试下载，检查网络与磁盘。PR 没字幕：确认导入的是本次 XML，PNG 目录未移动，字幕轨道启用且无缺失素材。识别人不对：声纹仅粗分组，回人工修正。原视频打不开：检查原路径与格式。故障反馈只提供脱敏日志、版本与复现步骤，不公开视频、API Key 或含隐私的文稿。
